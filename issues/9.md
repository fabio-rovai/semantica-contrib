### Summary

In `SHACLGenerator._attach_property_shapes()` (`ontology/ontology_generator.py`), a property with no declared `domain` is attached to **every** node shape:

```python
else:
    # No domain declared → attach to all shapes
    self.logger.debug(f"Property '{pname}' has no domain — attaching to all node shapes")
    for node_shape in graph.node_shapes:
        node_shape.property_shapes.append(self._build_property_shape(prop))
```

When that property is `required`, the generator emits `sh:minCount 1` on every class in the ontology. Missing domain information is treated as "applies universally" rather than "unknown", so the generated shapes reject data that the ontology permits.

### Version

semantica 0.6.5, Python 3.13.

### Reproduction

```python
from semantica.ontology.ontology_generator import SHACLGenerator

onto = {
    "classes": [{"name": "Person"}, {"name": "Organization"}],
    "properties": [
        {"name": "fullName", "type": "datatype", "domain": "Person", "range": "string", "required": True},
        {"name": "taxIdentifier", "type": "datatype", "range": "string", "required": True},  # no domain
    ],
}
gen = SHACLGenerator()
print(gen.serialize(gen.generate(onto), "turtle"))
```

### Actual

`taxIdentifier` appears with `sh:minCount 1` on **both** `PersonShape` and `OrganizationShape`. Every Person instance is now required to carry a tax identifier.

### Expected

An undeclared domain should produce no property shape, or a property shape with no `sh:minCount`, or an explicit opt-in flag such as `attach_undomained=True`. A visible warning rather than a debug-level log would also help, since the current behaviour silently invents constraints that the source ontology never stated.

### Interaction with quality_tier="strict"

`_apply_quality_tier()` sets `closed=True` on all shapes in the strict tier. Combined with the above, strict-tier shapes both require properties that were never scoped to the class and forbid everything not enumerated. That combination will reject essentially any real dataset.
