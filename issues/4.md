### Summary

Exporting one knowledge graph to `turtle` and to `ntriples` produces two graphs that are not isomorphic. The serializers are independent string builders that disagree on both subject identity and literal datatype.

### Version

semantica 0.6.5, Python 3.13.

### Reproduction

```python
from semantica.kg.graph_builder import GraphBuilder
from semantica.export.methods import export_rdf

source = {"entities": [{"id": "Acme Corp", "name": "Acme Corp", "type": "ORG", "confidence": 0.91}],
          "relationships": []}
kg = GraphBuilder(resolve_conflicts=False).build(sources=[source])
export_rdf(kg, "out.ttl", format="turtle")
export_rdf(kg, "out.nt", format="ntriples")
```

### Actual

`out.ttl`:

```turtle
<Acme Corp> a <ORG> ;
    semantica:confidence 0.91 .
```

`out.nt`:

```
<https://semantica.dev/ns#Acme Corp> <...#type> <https://semantica.dev/ns#ORG> .
<https://semantica.dev/ns#Acme Corp> <https://semantica.dev/ns#confidence> "0.91"^^<http://www.w3.org/2001/XMLSchema#float> .
```

Two divergences from the same input:

1. **Subject and type identity.** Turtle emits the raw value as a relative reference; N-Triples prefix-expands it into `https://semantica.dev/ns#`. These are different nodes. Anything that exports Turtle for review and N-Triples for loading gets two different graphs.
2. **Literal datatype.** `0.91` bare in Turtle is `xsd:decimal` by the Turtle grammar; N-Triples types it `xsd:float`. `xsd:decimal` and `xsd:float` are disjoint in the XSD value space, so a SHACL `sh:datatype` constraint or an OWL range that holds for one export fails for the other.

### Expected

All four serializers should be projections of one graph model. A property-based test asserting `rdflib.compare.isomorphic()` across `turtle`, `ntriples`, `jsonld` and `rdfxml` for the same input would pin this down permanently.

### Suggested fix

Build an `rdflib.Graph` once in `export_to_rdf()` and let rdflib serialize to each format. rdflib is already a required dependency. That removes four hand-written serializers and this whole class of divergence at the same time.
